# Publicación en GitHub Pages

Este proyecto incluye un flujo de GitHub Actions que compila el sitio estático con la ruta base correcta para `https://blackm3nma-leyva.github.io/irving-leyva-cv/` y publica el directorio `dist/public`.

En el repositorio, abra **Settings → Pages** y seleccione **GitHub Actions** como fuente de publicación. Después de que el flujo `Desplegar en GitHub Pages` termine correctamente, el sitio estará disponible en la URL indicada arriba. Los siguientes cambios enviados a la rama `main` actualizarán el sitio automáticamente.
